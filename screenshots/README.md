# Screenshots

This directory should contain screenshots of the GraphPilot application for the README.

Required screenshots:
- dashboard.png - Dashboard overview
- explorer.png - Graph Explorer with visualization
- impact.png - Impact Analysis showing affected services
- incidents.png - Incidents list with severity indicators
- assistant.png - AI Assistant chat interface

To capture screenshots:
1. Navigate to https://graph-pilot.vercel.app
2. Use browser screenshot tools (Chrome DevTools, Snipping Tool, etc.)
3. Save as PNG files in this directory
4. Update README.md to reference them
